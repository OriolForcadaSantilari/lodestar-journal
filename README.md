# Lodestar Journal

A daily journal that asks you one question a day, for a year of self-reflection.

**[Download on the App Store](https://apps.apple.com/es/app/lodestar-journal/id6776577867)**

## What it does
- 349 introspective prompts, one per day, to help you think through important changes in your life
- Daily reminder at the time you choose
- English and Spanish, following your device language
- Private by design: entries stay on your phone. No accounts, no analytics, no ads

## Built with
`React Native` `Expo` `JavaScript` `React Navigation` `AsyncStorage` `Expo Notifications` `i18next`

Designed and built by me with AI-assisted development (Claude), and published through Apple's App Store review.

## Run it locally
```bash
npm install
npx expo start
```
